# ADR-001: Bastion para Acesso Administrativo

**Status:** Aceita  
**Data:** Entrega 1 / Mantida na Entrega 2  
**Decisores:** Grupo AutoPrime  

## Contexto
No contexto de acessar por SSH as VMs que ficam na sub-rede privada, sem IP público, diante de precisar administrar essas instâncias sem expor a aplicação ou o banco diretamente à internet.

## Decisão
Decidimos por manter um host Bastion (`e2-micro`) na sub-rede pública com IP público estático, com porta 22 liberada exclusivamente para o CIDR do grupo (R7) e autenticação restrita a chaves SSH (S1), servindo como jump host (`ssh -J`) para a VM privada.

## Alternativas Descartadas
Descartamos colocar IP público direto na VM da aplicação/banco e descartamos deixar a sub-rede privada sem ponto de acesso seguro.

## Consequências
Para alcançar segurança em camadas, controle restrito de entrada e conformidade com os requisitos R5 e R6 do edital, aceitando o custo mínimo adicional de uma instância `e2-micro`.

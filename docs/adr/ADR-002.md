# ADR-002: Cloud NAT Gerenciado

**Status:** Aceita  
**Data:** Entrega 1 / Entrega 2  
**Decisores:** Grupo AutoPrime  

## Contexto
No contexto de dar saída para a internet às máquinas da sub-rede privada, diante de precisar instalar e atualizar pacotes sem expor essas máquinas.

## Decisão
Decidimos por Cloud NAT gerenciado.

## Alternativas Descartadas
Descartamos NAT em instância (mais uma VM para pagar e gerenciar) e não ter saída (impediria instalar e atualizar).

## Consequências
Para alcançar praticidade e facilidade de escalar, aceitando que ele é cobrado por hora mesmo sem uso e, no cenário de trabalho, é o item mais caro.

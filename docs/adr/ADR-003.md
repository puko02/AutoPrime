# ADR-003: Banco MariaDB em VM Própria

**Status:** Substituída pelo ADR-004  
**Data:** Entrega 1  
**Decisores:** Grupo AutoPrime  

## Contexto
No contexto de guardar os dados de carros, clientes e vendas do AutoPrime, diante de escolher entre gerenciar o banco por conta própria ou usar um serviço do Google.

## Decisão
Decidimos por instalar o MariaDB numa VM própria, na sub-rede privada.

## Alternativas Descartadas
Descartamos o banco gerenciado do Google (Cloud SQL).

## Consequências
Para alcançar uma maior liberdade na hora de configurar, manipular e utilizar em geral o banco de dados, aceitando que o grupo fica responsável por toda a parte de backup, atualizações e segurança do banco.

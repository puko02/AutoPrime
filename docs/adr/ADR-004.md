# ADR-004: Consolidação dos Serviços em VM Privada Conteinerizada

**Status:** Aceita (substitui formalmente o ADR-003)  
**Data:** Entrega 2  
**Decisores:** Grupo AutoPrime  

## Contexto
No contexto de implantar o AutoPrime (frontend, backend e banco) na Entrega 2, diante de buscar o melhor custo-benefício financeiro para o grupo sem abrir mão do isolamento de rede exigido pelo edital (R5 e R4).

## Decisão
Decidimos por consolidar o Frontend (Angular/Nginx), o Backend (Spring Boot) e o Banco de Dados (MariaDB) em contêineres Docker orquestrados via Docker Compose dentro de uma VM `e2-medium` localizada na sub-rede privada, sem nenhum IP público associado, utilizando o Cloud NAT para saída de internet e o Bastion para acesso SSH administrativo.

## Alternativas Descartadas
Descartamos manter 4 instâncias Compute Engine separadas (conforme rascunho inicial da Entrega 1) e descartamos o uso de Cloud SQL gerenciado na Entrega 2 (alto custo contínuo).

## Consequências
Para alcançar gerenciamento simplificado, redução de mais de 60% nos custos computacionais do grupo e conformidade total com os requisitos R4 (saída exclusiva via Cloud NAT) e R5 (recurso privado sem IP público), aceitando que, se esta VM privada falhar, todos os contêineres ficam indisponíveis até a recuperação da instância.
